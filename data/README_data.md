# 데이터 안내

본 프로젝트는 한국언론진흥재단의 2023년 및 2025년 「언론인 조사」 데이터를 활용하여 수행한 분석입니다.

## 1. 사용 데이터

| 구분          | 파일명                 |   표본 수 | 활용 목적    |
| ----------- | ------------------- | -----: | -------- |
| 2023 언론인 조사 | journalist_2023.sav | 2,011명 | 기준 시점 분석 |
| 2025 언론인 조사 | journalist_2025.sav | 2,020명 | 비교 시점 분석 |

## 2. 원본 데이터 포함 여부

본 제출 ZIP에는 원본 조사 데이터 파일을 포함하지 않았습니다.

원본 데이터는 한국언론진흥재단 언론통계 자료실에서 제공되는 공식 자료를 기준으로 활용했습니다. 다만 원본 데이터의 재배포 가능 여부를 고려하여, 제출 산출물에는 원본 데이터 파일 대신 분석 코드, 변수 매핑, 분석 결과표, 시각화 자료, 최종 보고서를 중심으로 포함했습니다.

분석을 재현하려면 한국언론진흥재단 언론통계 자료실에서 원본 데이터를 내려받은 뒤 아래 위치에 배치하면 됩니다.

| 연도   | 배치 경로                        |
| ---- | ---------------------------- |
| 2023 | data/raw/journalist_2023.sav |
| 2025 | data/raw/journalist_2025.sav |

## 3. 분석 주제

본 프로젝트의 주제는 다음과 같습니다.

기자들은 AI를 믿는가, 견디는가?
2023·2025 언론인 조사로 본 생성형 AI 시대 저널리즘 전환 스트레스

분석의 핵심은 단순히 AI 활용률이 증가했는지를 확인하는 데 그치지 않고, 생성형 AI 확산 과정에서 언론인이 경험하는 디지털 피로, 역할 변화 부담, 번아웃, 전환 스트레스를 함께 살펴보는 것입니다.

## 4. 주요 분석 변수

| 변수 또는 지표  | 설명                                    |
| --------- | ------------------------------------- |
| AI 활용 여부  | 언론인이 AI 관련 도구를 업무에 활용하는지 여부           |
| AI 기대 인식  | AI가 업무 효율, 정확성, 신속성에 기여할 것이라는 인식      |
| AI 리스크 인식 | AI 활용으로 인한 저작권, 일자리 위협, 오보 가능성에 대한 우려 |
| 디지털 피로    | 디지털 환경 변화와 기술 적응 과정에서 느끼는 피로감         |
| 역할 실행 갭   | 언론인 역할의 중요도와 실제 실행 수준 사이의 차이          |
| 번아웃       | 업무 탈진 및 직업 회의와 관련된 지표                 |
| 직업 만족도    | 언론인 직무에 대한 전반적 만족 수준                  |
| 매체 유형     | 신문사, 방송사, 인터넷언론사, 뉴스통신사 구분            |

## 5. 변수 매핑 방식

2023년과 2025년 조사는 문항 번호와 일부 표현이 다르기 때문에, 단순히 같은 열 이름을 비교하지 않았습니다.

본 프로젝트에서는 문항의 의미를 기준으로 비교 가능한 변수를 선별하고, 2023년 변수와 2025년 변수를 매핑하여 분석했습니다.

디지털 피로, 직업 만족도, 번아웃, AI 기대, AI 리스크 관련 문항은 연도별 문항 번호가 다르기 때문에 변수 매핑 기준을 별도로 정리하여 분석에 활용했습니다.

## 6. 공식 통계 검산

분석 과정에서 공식 보고서 또는 기초 통계와 비교 가능한 항목은 검산을 수행했습니다.

| 항목     | 2023년 | 2025년 |     변화 |
| ------ | ----: | ----: | -----: |
| AI 활용률 | 54.3% | 58.1% | +3.8%p |
| 디지털 피로 | 38.3% | 45.5% | +7.2%p |

본 프로젝트는 AI 활용률 증가보다 디지털 피로 증가 폭이 더 크다는 점에 주목했습니다.

## 7. JTSI 지수

본 프로젝트에서는 언론인의 전환 부담을 종합적으로 보기 위해 JTSI를 구성했습니다.

JTSI는 Journalism Transformation Stress Index의 약자로, 생성형 AI 시대 언론인이 경험하는 전환 스트레스를 집단 단위로 비교하기 위한 분석 지표입니다.

JTSI는 다음 네 요소를 z-score로 표준화한 뒤 합산하여 구성했습니다.

| 구성 요소     | 의미                        |
| --------- | ------------------------- |
| 디지털 피로    | 디지털 환경 변화로 인한 피로 수준       |
| AI 리스크 인식 | AI 활용에 대한 위험 인식           |
| 역할 실행 갭   | 요구되는 역할과 실제 수행 가능성 사이의 차이 |
| 번아웃       | 업무 소진 및 심리적 부담            |

JTSI는 개인을 진단하는 임상 지표가 아니라, 집단별 전환 부담을 비교하기 위한 탐색적 분석 지표입니다.

## 8. 주요 분석 방법

| 분석 방법        | 활용 목적                          |
| ------------ | ------------------------------ |
| 빈도분석 및 비율 비교 | 연도별 AI 활용률과 디지털 피로 수준 비교       |
| Welch t-test | AI 활용자와 비활용자 간 평균 차이 검정        |
| Cohen's d    | 집단 간 차이의 효과크기 확인               |
| ANOVA        | 유형별 평균 차이 검토                   |
| eta squared  | ANOVA 결과의 효과크기 확인              |
| 카이제곱 검정      | 범주형 변수 간 관련성 검토                |
| Cramér's V   | 카이제곱 검정 결과의 관련성 크기 확인          |
| 2×2 유형화      | AI 활용 여부와 전환 스트레스 수준에 따른 집단 분류 |

## 9. 주요 산출물 위치

| 폴더               | 내용                    |
| ---------------- | --------------------- |
| notebooks/       | 단계별 분석 노트북            |
| src/             | 변수 매핑 및 통계 보조 함수      |
| outputs/tables/  | 검산표, 집단 비교표, 통계검정 결과표 |
| outputs/figures/ | 최종 시각화 이미지            |

| data/            | 데이터 출처 및 활용 방식 설명     |

## 10. 유의사항

원본 데이터는 제출 ZIP에 포함하지 않았습니다.

분석 재현을 원하는 경우 원본 SAV 파일을 data/raw/ 폴더에 배치한 뒤 notebooks/ 폴더의 노트북을 번호 순서대로 실행하면 됩니다.
